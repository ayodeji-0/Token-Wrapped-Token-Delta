# Token-Wrapped-Token-Delta
 Statistical exploration of liquidity inefficiencies caused by wrapped tokens in select crypto markets. Can also use trends identified to determine trade entry and exit positions - Z scoring, comparing with altcoins, some form of statistical arbitrage opportunity exists here.

 Price Differences (2Y) shown below.
 One can easily observe how the spread blooms and diverges during bull runs with convergence shown in bearish periods.
